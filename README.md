# Internal-Marks-Calculator

# Project Description – Internal Marks Calculator

The Internal Marks Calculator is a Python-based project designed to calculate students' internal assessment marks, assign grades, and determine their pass or fail status. The project uses a modular programming approach by dividing the tasks into separate functions and importing them from a user-defined Python package called `marks_pkg`.

The program accepts marks for two tests and one assignment from the user. It calculates the total internal marks using a weighted average, where Test 1 carries 30%, Test 2 carries 30%, and the Assignment carries 40%.

Before calculating the result, the program validates the entered marks to ensure that each score is between 0 and 100. If invalid marks are entered, the program displays an error message. Otherwise, it calculates the final score, assigns a grade from A to F, and displays the student's pass or fail status.

### Objectives

1. To calculate students' internal assessment marks.
2. To validate marks entered by the user.
3. To apply weighted percentages to different assessments.
4. To assign grades based on the total marks.
5. To determine whether a student has passed or failed.
6. To understand Python functions and user-defined packages.

### Concepts Used

- Python functions
- User-defined packages and modules
- Conditional statements (`if`, `elif`, `else`)
- User input and output
- Data validation
- Mathematical calculations
- Function importing

### Conclusion

The Internal Marks Calculator simplifies the process of calculating internal assessment results. It reduces manual calculations, ensures proper mark validation, and provides accurate grades and pass/fail results. This project demonstrates the practical use of Python functions, modular programming, and packages in developing a simple real-world application.
